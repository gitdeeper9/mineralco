╔════════════════════════════════════════════════════════════════════════════╗
║                         PROJECT DESCRIPTION                                ║
╠════════════════════════════════════════════════════════════════════════════╣
║                                                                            ║
║   MINERALCO (Mineral Intelligence Network for Equation-of-state Research,  ║
║   Atomic Lattice COmputation) is a seven-parameter computational           ║
║   framework for the systematic characterisation of mineral behaviour       ║
║   under the extreme pressure and temperature conditions that prevail       ║
║   throughout Earth's interior.                                             ║
║                                                                            ║
╚════════════════════════════════════════════════════════════════════════════╝


╔════════════════════════════════════════════════════════════════════════════╗
║                   THE CRYSTAL INTELLIGENCE SEPTUPLET (CIS)                 ║
╠════════════════════════════════════════════════════════════════════════════╣
║                                                                            ║
║   ┌──────┬─────────────────────────┬──────────────┬───────────────┐      ║
║   │  #   │ Parameter               │ Symbol       │ Weight (w_i)  │      ║
║   ├──────┼─────────────────────────┼──────────────┼───────────────┤      ║
║   │  1   │ Bulk Modulus            │ K₀           │     0.28      │      ║
║   │  2   │ Lattice Parameters      │ a, b, c      │   (from XRD)  │      ║
║   │  3   │ Pressure Derivative     │ K'           │     0.17      │      ║
║   │  4   │ Crystal Symmetry        │ S_y          │     0.13      │      ║
║   │  5   │ Thermal Expansion       │ α            │     0.10      │      ║
║   │  6   │ Grüneisen Parameter     │ γ            │     0.09      │      ║
║   │  7   │ Specific Volume         │ V_s          │     0.19      │      ║
║   └──────┴─────────────────────────┴──────────────┴───────────────┘      ║
